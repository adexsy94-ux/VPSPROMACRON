MERGE-FIRST KYC RECONCILIATION V10 — STREAMLIT CLOUD DEPLOYMENT

WHY THE ERROR HAPPENED
======================
The previous package used a versioned dependency file:
    requirements_merge_first_v9.txt

Streamlit Community Cloud normally auto-installs Python dependencies
from a file named exactly:
    requirements.txt

pandas can be installed while openpyxl is missing because openpyxl is
an optional Excel dependency. When the app reaches pd.read_excel(...),
pandas then raises:
    ImportError: Import openpyxl failed

PUT THESE FILES IN GITHUB
=========================
In the SAME folder:

    merge_first_reconciliation_v10.py
    requirements.txt

requirements.txt already contains:
    streamlit>=1.38,<2
    pandas>=2.2,<3
    numpy>=1.26
    openpyxl>=3.1.5
    xlsxwriter>=3.2
    xlrd>=2.0.1

DEPLOYMENT STEPS
================
1. Commit both files to GitHub.
2. Confirm the dependency file is named exactly requirements.txt.
3. In Streamlit Community Cloud, set the main file to:
      merge_first_reconciliation_v10.py
4. Reboot/redeploy the app so dependencies are installed again.

If your app is inside a subfolder, put requirements.txt in that same
app folder or at the repository root.

The V10 code also checks for openpyxl at startup and gives a clearer
deployment message if it is ever missing.
