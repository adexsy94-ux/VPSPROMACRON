MERGE-FIRST KYC RECONCILIATION V13
STREAMLIT DEPENDENCY FIX

WHAT THE TRACEBACK PROVES
=========================
The app started in Streamlit Cloud but Python could not import openpyxl.
This means openpyxl was NOT installed in the environment used by the app.

The reconciliation code cannot read .xlsx files without an Excel reader.
This is a deployment/repository dependency problem, not a Macron/VPS
reconciliation calculation error.

REQUIRED GITHUB LAYOUT
======================
Recommended simplest layout:

    vpspromacron/
    ├── merge_first_reconciliation_v13.py
    └── requirements.txt

requirements.txt MUST be named exactly:
    requirements.txt

It MUST contain:
    streamlit>=1.49,<2
    pandas>=2.2,<3
    numpy>=1.26,<3
    openpyxl==3.1.5
    xlsxwriter>=3.2
    xlrd>=2.0.1

IMPORTANT: CHECK FOR COMPETING DEPENDENCY FILES
================================================
Streamlit Community Cloud uses only one dependency configuration.
If your repository contains files such as:
    uv.lock
    Pipfile
    environment.yml
    pyproject.toml
Streamlit may use another dependency manager instead of the
requirements.txt you intended.

For this app, the simplest setup is to keep ONE requirements.txt beside
the Python entrypoint and remove/rename old dependency files that you
are not intentionally using.

AFTER COMMITTING TO GITHUB
==========================
1. Confirm both files are visible on GitHub.
2. In Streamlit Cloud choose Manage app.
3. Reboot the app.
4. If necessary, delete and redeploy using:
       merge_first_reconciliation_v13.py
   as the main file.
5. Open the build logs and confirm you can see openpyxl being installed.

V13 CHANGE
==========
V12 imported openpyxl at the top of the script. If the dependency was
missing, the entire app crashed before the Streamlit UI could load.

V13 no longer imports openpyxl at module startup. Excel support is
checked only when an Excel file is read, so deployment errors are much
clearer. The app still REQUIRES openpyxl for .xlsx input.

NO packages.txt IS NEEDED
=========================
openpyxl is a Python package, so it belongs in requirements.txt.
